# 正式上線檢查表

> 狀態：草案，等待專案負責人確認。

## 上線前

- [ ] 工作內容與 Pull Request 範圍一致。
- [ ] Codex 已檢查完整 diff。
- [ ] TypeScript 型別檢查通過。
- [ ] ESLint 通過（0 錯誤、0 警告）。
- [ ] Production build 通過。
- [ ] 自動化測試通過（於 Production build 完成後執行 `npm run test:smoke` 核心唯讀測試）。
- [ ] Vercel Preview 可正常開啟。
- [ ] 核心 smoke tests 通過（自動化測試涵蓋可用性、導覽、SEO 與表單驗證；人工煙霧測試確認視覺排版與互動）。
- [ ] 手機與桌面主要畫面已檢查。
- [ ] 新增或修改的環境變數已記錄。
- [ ] 沒有密鑰、密碼、Token 或個人資料進入 Git。
- [ ] 資料庫異動已在非正式資料庫驗證。
- [ ] 資料庫異動已有備份與回復方案。
- [ ] 回復上一正常版本的方法已確認。
- [ ] 明顯的前台、內容或品牌變更已由專案負責人確認。

## 上線中

- [ ] 確認目前發布版本與 Commit。
- [ ] 觀察 Vercel 部署是否成功。
- [ ] 若有 migration，依核准順序執行並保存結果。
- [ ] 不同時進行無關的正式環境設定修改。

## 上線後

- [ ] 首頁可正常載入。
- [ ] 導覽至主要頁面正常。
- [ ] 報價表單基本驗證正常。
- [ ] 文章列表與文章內容正常。
- [ ] 夥伴列表正常。
- [ ] 客戶好評正常。
- [ ] 後台登入頁正常。
- [ ] 管理員可登入與登出，若本次修改涉及身分驗證。
- [ ] 圖片可正常顯示與上傳，若本次修改涉及媒體。
- [ ] 沒有新增大量錯誤紀錄。
- [ ] CHANGELOG 與版本紀錄已更新。

## 必須回復的情況

- 首頁或主要導覽無法使用。
- 報價流程無法送出或出現資料外洩風險。
- 後台權限失效或未授權使用者可存取管理功能。
- 文章、評論或夥伴資料大量遺失或顯示錯誤。
- 錯誤率明顯升高，且無法在短時間內確認原因。
- migration 只完成部分步驟，造成新舊版本不相容。

## 回復後

- [ ] 確認上一正常版本已恢復。
- [ ] 再次執行核心 smoke tests。
- [ ] 暫停原 Pull Request 的再次發布。
- [ ] 記錄事件時間、影響、原因與後續修正方式。
- [ ] 修正必須重新經過完整 Preview 與驗收流程。
